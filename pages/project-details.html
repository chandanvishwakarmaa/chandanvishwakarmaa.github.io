PROJECT FILE // 01

Electricity Price Forecasting using Machine Learning

Status: PRODUCTION DEPLOYED | Compiled & Verified

Predicting spot pricing structures on state level power pools is highly demanding due to sharp peak events, generation limits, seasonal temperature variables, and localized grid transmission constraints. In this project, a fully optimized end-to-end Machine Learning pipeline was constructed on 112k+ rows of historical logs to forecast energy prices with severe accuracy, achieving a final validation score of 7.7% MAPE.

The Feature Engineering Pipeline

Data Science success lives or dies by feature clarity. I constructed a 79-dimensional logical dataset with zero target leaks:

# Sample Feature Engineering Snippet def engineer_features(df): # Cyclical Calendar Transformations df['hour_sin'] = np.sin(df['Hour'] * (2 * np.pi / 24)) df['hour_cos'] = np.cos(df['Hour'] * (2 * np.pi / 24)) # Lag Predictor Sequences for lag in [1, 2, 24, 48]: df[f'price_lag_{lag}'] = df['Price'].shift(lag) # Moving Statistical Window Arrays df['rolling_mean_6h'] = df['Price'].shift(1).rolling(window=6).mean() df['rolling_std_24h'] = df['Price'].shift(1).rolling(window=24).std() return df.dropna()

Evaluated Estimators & Baseline Optimization

A sequential baseline tree parameter was set using standard Linear Regression, generating a baseline MAPE of 18.2%. Transitioning to recursive ensembles, the metrics evolved as follows:

  • Model 1: Linear Regression Baseline → 18.2% MAPE (Prone to sudden season and weather swings)
  • Model 2: Decision Tree Regressor → 11.4% MAPE (Higher variance, overfits peak hours)
  • Model 3: Random Forest Regressor [Optimized] → 7.7% MAPE (Highest stability: handles localized weather spikes perfectly)

Production-Grade Pipeline Blueprint

To guarantee seamless deployments, the clean engineering process was encapsulated in modular Scikit-learn Pipelines:

from sklearn.pipeline import Pipeline from sklearn.preprocessing import StandardScaler from sklearn.impute import SimpleImputer ml_pipeline = Pipeline([ ('imputer', SimpleImputer(strategy='median')), ('scaler', StandardScaler()), ('regressor', RandomForestRegressor(n_estimators=100, max_depth=15, random_state=42)) ])
